Universités mondiales : ce que le pays dit de ses universités

Une base SQLite de 2 336 universités réparties dans 115 pays, interrogée en SQL et en Python pour mesurer le lien entre le développement d'un pays et la performance de ses universités — puis restituée dans un classeur Excel généré automatiquement.

01

Problématique

Le classement du Times Higher Education compare les universités du monde entier comme si elles partaient toutes du même point. Or une université ne fonctionne pas dans le vide : elle dépend de la richesse de son pays, du niveau d'éducation de sa population, de son ouverture sur l'étranger.

La question

Le niveau de développement d'un pays — PIB par habitant, alphabétisation, part d'étudiants internationaux, parité — se retrouve-t-il dans la performance de ses universités ?

La contrainte : n'utiliser que os, sqlite3 et openpyxl. Pas de Pandas, pas de Matplotlib — tout le calcul passe par SQL et Python pur.

Projet mené à trois avec Glaineta et Martin ; requêtes SQL, fonctions Python et reporting Excel ont été répartis à parts égales.

Quatre obstacles, quatre réponses

Les difficultés qui ont vraiment façonné le code.

Obstacle
Les jointures entre 4 tables dupliquaient des lignes et faussaient les moyennes.
Réponse
Les indicateurs globaux sont calculés par des sous-requêtes séparées, table par table.
Obstacle
La recherche d'universités devait accepter des filtres facultatifs : pays, année, seuils de score.
Réponse
Les conditions sont ajoutées à la requête seulement si le filtre est renseigné, toujours avec des marqueurs ? — ce qui protège aussi des injections SQL.
Obstacle
Classer les pays par tranche de PIB en Python demandait 9 listes et 68 lignes.
Réponse
Un seul SELECT avec CASE WHEN fait tout le travail : 35 lignes, plus lisibles et plus rapides.
Obstacle
Un pays avec une seule université brillante se retrouvait en tête du Top 10.
Réponse
Seuls les pays d'au moins 20 universités sont retenus (HAVING), et le score est pondéré : score × nb / (nb + 20).
« Les universités mixtes obtiennent les meilleurs scores » Entre 40 et 60 % de femmes : meilleures moyennes en enseignement et en recherche

def rechercher_universites(conn, pays=None, annee=None,
                          min_enseig=None, min_rech=None, limite=50):
    """Filtre les universités selon des critères optionnels, triées par rang."""
    # Validation des types d'entrée
    if pays is not None and not isinstance(pays, str):
        raise ValueError("'pays' doit être une chaîne de caractères")
    if annee is not None and not isinstance(annee, (int, float)):
        raise ValueError("'annee' doit être un entier")

    # Requête SQL de base
    req = """
    SELECT c.rang, u.nom_univ, p.nom_pays,
           c.score_enseig, c.score_qualite_rech, c.score_the
    FROM classements c
    JOIN universites u ON c.id_univ = u.id_univ
    JOIN pays p ON u.id_pays = p.id_pays
    WHERE p.pib_par_hab >= 0
    """

    # Ajout dynamique des critères optionnels
    conditions = []
    parametres = []

    if pays is not None:
        conditions.append("p.nom_pays = ?")
        parametres.append(pays)
    if annee is not None:
        conditions.append("c.annee = ?")
        parametres.append(annee)
    if min_enseig is not None:
        conditions.append("c.score_enseig >= ?")
        parametres.append(min_enseig)
    if min_rech is not None:
        conditions.append("c.score_qualite_rech >= ?")
        parametres.append(min_rech)

    if conditions:
        req += " AND " + " AND ".join(conditions)  # pas de WHERE dupliqué !

    req += " ORDER BY c.rang LIMIT ?"
    parametres.append(limite)

    curseur = conn.cursor()
    curseur.execute(req, parametres)
    return [tuple(ligne) for ligne in curseur.fetchall()]
def stats_pib_vs_perf(connexion, annee=2025):
    """Catégorise les universités selon le PIB/hab du pays et calcule
    la moyenne de score_enseig, score_qualite_rech, score_the."""
    curseur = connexion.cursor()
    req = """
    SELECT
        ROUND(AVG(CASE WHEN p.pib_par_hab <= 1135
                       THEN c.score_enseig END), 4) AS moy_ens_faible,
        ROUND(AVG(CASE WHEN p.pib_par_hab BETWEEN 1136 AND 4495
                       THEN c.score_enseig END), 4) AS moy_ens_inter,
        ROUND(AVG(CASE WHEN p.pib_par_hab >= 4496
                       THEN c.score_enseig END), 4) AS moy_ens_eleve,

        ROUND(AVG(CASE WHEN p.pib_par_hab <= 1135
                       THEN c.score_qualite_rech END), 4) AS moy_rech_faible,
        ROUND(AVG(CASE WHEN p.pib_par_hab BETWEEN 1136 AND 4495
                       THEN c.score_qualite_rech END), 4) AS moy_rech_inter,
        ROUND(AVG(CASE WHEN p.pib_par_hab >= 4496
                       THEN c.score_qualite_rech END), 4) AS moy_rech_eleve,

        ROUND(AVG(CASE WHEN p.pib_par_hab <= 1135
                       THEN c.score_the END), 4) AS moy_the_faible,
        ROUND(AVG(CASE WHEN p.pib_par_hab BETWEEN 1136 AND 4495
                       THEN c.score_the END), 4) AS moy_the_inter,
        ROUND(AVG(CASE WHEN p.pib_par_hab >= 4496
                       THEN c.score_the END), 4) AS moy_the_eleve
    FROM classements AS c
    JOIN universites AS d ON c.id_univ = d.id_univ
    JOIN pays AS p ON d.id_pays = p.id_pays
    WHERE c.annee = ?
    """
    curseur.execute(req, (annee,))
    ligne = curseur.fetchone()  # fetchone() car une seule ligne de résultats

    return {
        "Faible":       {"moy_ens": ligne[0], "moy_rech": ligne[3], "moy_the": ligne[6]},
        "Intermédiaire": {"moy_ens": ligne[1], "moy_rech": ligne[4], "moy_the": ligne[7]},
        "Elevé":        {"moy_ens": ligne[2], "moy_rech": ligne[5], "moy_the": ligne[8]},
    }
def top10_pays_multi_annees(connexion, annee_deb=2020, annee_fin=2025,
                            critere="score_enseig"):
    """Top 10 des pays avec ≥ 20 universités, score pondéré sur la période."""
    pascur = connexion.cursor()

    # Moyenne + comptage par pays, filtrée sur la période
    req = f"""
    SELECT p.nom_pays, AVG(c.{critere}) AS moy, COUNT(DISTINCT u.id_univ) AS nb
    FROM classements c
    JOIN universites u ON c.id_univ = u.id_univ
    JOIN pays p ON u.id_pays = p.id_pays
    WHERE c.annee BETWEEN ? AND ?
    GROUP BY p.nom_pays
    HAVING nb >= 20
    """

    res = []
    # Pondération : score × nb / (nb + 20) → évite qu'un pays à 1 univ top parasite
    for r in pascur.execute(req, (annee_deb, annee_fin)):
        score = r["moy"] * r["nb"] / (r["nb"] + 20)
        res.append((r["nom_pays"], round(score, 3), r["nb"]))

    return sorted(res, key=lambda x: x[1], reverse=True)[:10]

À retenir

La réponse

Oui : richesse, alphabétisation, ouverture internationale et parité se retrouvent dans les scores des universités. Ce sont des liens observés, pas des relations de cause à effet.

Ce que le projet démontre

Des requêtes SQL multi-tables, un code Python sans bibliothèque d'analyse, et un reporting Excel entièrement automatisé.

Les limites

Seules les universités déjà classées par le THE figurent dans la base, et les écarts sont décrits par des moyennes, sans test statistique.
