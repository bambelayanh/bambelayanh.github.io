Le cycle solaire : de la régression harmonique au deep learning

277 ans de données mensuelles (SILSO, 1749–2026) : construction d'un modèle statistique harmonique rigoureusement diagnostiqué et confronté aux prévisions NOAA, puis extension par décomposition en valeurs singulières, visualisation 3D de la rotation différentielle du Soleil, et prévision par réseau LSTM — pour tester si l'apprentissage profond peut surpasser la connaissance structurelle du phénomène.

01

Problématique

Le nombre de taches solaires est l'indicateur historique de l'activité magnétique du Soleil, suivi quasi continûment depuis le XVIIIe siècle. Il présente une périodicité connue d'environ 11 ans (cycle de Schwabe), mais une intensité qui varie fortement et reste partiellement mal comprise d'un cycle à l'autre.

Question centrale

Peut-on caractériser rigoureusement la structure temporelle du cycle solaire, construire un modèle honnête de sa dynamique, puis évaluer sa capacité prédictive face à des références externes (NOAA) et à un protocole de validation rétrospective — plutôt que de se contenter d'un ajustement qui paraît convaincant en apparence ?

Le projet pousse ensuite cette question plus loin : une approche fondée sur les données seules (deep learning) peut-elle surpasser une approche fondée sur la connaissance structurelle du phénomène physique — et si oui, à quel horizon de prévision ?

02

Démarche & modèle conçu

Le cœur du projet est un modèle de régression harmonique construit progressivement par ajout de composantes, chacune validée par test F avant d'être retenue.

1

Analyse spectrale

Le périodogramme de la série centrée identifie une fréquence dominante correspondant à une période de 10,82 ans — cohérente avec la valeur canonique du cycle de Schwabe — et un pic secondaire à 93,75 ans, candidat prudent pour une composante longue de type Gleissberg.

2

Choix du schéma multiplicatif

L'amplitude de chaque cycle croît avec son niveau (Â = 3,18 + 1,77 N, R² = 0,973), orientant vers un schéma multiplicatif, confirmé par transformation logarithmique — avec la réserve qu'une partie de cette corrélation est mécanique plutôt que purement structurelle.

3

Construction progressive du modèle harmonique

Trois modèles emboîtés sont ajustés par moindres carrés sur la série log-transformée, chaque ajout étant validé par test F (p < 10⁻⁷) :

4

Diagnostic honnête des résidus

Les résidus ne sont ni gaussiens (Shapiro-Wilk, p < 2,2×10⁻¹⁶) ni indépendants (Ljung-Box, p ≈ 0) à aucun horizon testé. Plutôt que de masquer cette limite, elle est documentée explicitement : mod3 décrit une composante périodique dominante, ce n'est pas un modèle de série temporelle complet.

5

Confrontation externe & backtesting

Le modèle aveugle (ajusté uniquement sur les données antérieures à 2019) surpasse le consensus du panel international NOAA/NASA/ISES 2019 sur le cycle 25 (−10,9 % d'écart contre −28,5 % pour NOAA). Mais un protocole de backtesting sur 7 cycles historiques révèle que ce résultat isolé était optimiste : l'erreur moyenne sur le temps long est de −20 %, du même ordre de grandeur que l'expertise humaine.

03

Extension : algèbre linéaire, 3D & deep learning

Trois phases complémentaires prolongent le modèle statistique initial, chacune mobilisant un outil différent sur les mêmes données solaires.

Phase B

Décomposition en valeurs singulières

La SVD appliquée au diagramme papillon (2 037 rotations × 50 bandes de latitude) montre qu'un seul mode capture 32 % de l'énergie du signal, et qu'une vingtaine de modes suffisent à dépasser 95 % — révélant une structure dominée par un nombre restreint de composantes cohérentes.

Phase C

Visualisation 3D & rotation différentielle

Reconstruction de la position réelle des taches solaires sur une sphère 3D interactive (Plotly), et validation empirique de la loi de Snodgrass & Ulrich sur la rotation différentielle du Soleil à partir d'un groupe de taches suivi sur plusieurs jours.

Phase D

Prévision par réseau LSTM

Un LSTM (PyTorch) est confronté au modèle harmonique et à une persistance naïve, à deux horizons (1 mois / 11 ans). Résultat nuancé : le classement des modèles s'inverse totalement selon l'horizon de prévision considéré.

04

Extraits de code clés

L'architecture LSTM (PyTorch) et sa baseline de comparaison — le modèle harmonique aveugle, ré-estimé en Python pour un protocole d'évaluation strictement identique entre les deux approches.

class LSTMForecaster(nn.Module):
    def __init__(self, input_size=1, hidden_size=32, num_layers=1, output_size=1):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        # x : (batch, seq_len, input_size)
        out, (h_n, c_n) = self.lstm(x)
        last_output = out[:, -1, :]   # on ne garde que le dernier pas de temps
        return self.fc(last_output)


def train_model(model, train_loader, n_epochs=100, lr=1e-3):
    """Boucle d'entraînement générique (court terme et long terme)."""
    model = model.to(device)
    criterion = nn.MSELoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    losses = []

    for epoch in range(n_epochs):
        model.train()
        epoch_loss = 0.0
        for X_batch, y_batch in train_loader:
            X_batch, y_batch = X_batch.to(device), y_batch.to(device)
            optimizer.zero_grad()
            predictions = model(X_batch)
            loss = criterion(predictions, y_batch)
            loss.backward()
            optimizer.step()
            epoch_loss += loss.item() * X_batch.size(0)

        epoch_loss /= len(train_loader.dataset)
        losses.append(epoch_loss)

    return model, losses

Le classement s'inverse entièrement selon l'horizon : le LSTM domine à court terme en exploitant l'information récente, mais le modèle harmonique — qui encode une connaissance structurelle du phénomène — l'emporte nettement à long terme. Aucune approche ne domine universellement.

07

Ce que ce projet démontre

Rigueur méthodologique

Diagnostic systématique des résidus, correction du biais de re-transformation (smearing de Duan), séparation stricte train/test sans fuite d'information, protocole de backtesting multi-cycles plutôt qu'une confrontation isolée.

Honnêteté scientifique

Une extension prometteuse (mod4, amplitude modulée) est explorée, testée, puis explicitement écartée après contrôle indépendant — documentée plutôt que silencieusement abandonnée.

Palette technique large

Un même jeu de données traité par quatre approches différentes : régression harmonique classique, algèbre linéaire (SVD), visualisation 3D interactive, deep learning (LSTM/PyTorch).

Esprit critique sur les résultats

Un résultat favorable isolé (mod3 bat le panel NOAA sur un cycle) est immédiatement nuancé par un backtesting plus large qui révèle une performance moyenne comparable — pas de sur-vente d'un résultat chanceux.
